# Tug a Tools

Tug a Tools is a simple tool rental concept app. It allows renters to browse a list of available tools and submit a rental request. The app then provides a quote for the rental period.

This repository contains a small Flask application that demonstrates the idea.

## Running the app

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the server:
   ```bash
   python app.py
   ```
3. Open your browser to `http://localhost:5000` to view the app.

The app stores data in memory only and is meant as a lightweight prototype.
